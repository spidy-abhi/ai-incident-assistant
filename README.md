# AI Incident Assistant

Enterprise AI Incident and Knowledge Assistant built with Java, Spring Boot and Spring AI.

## Goal

The application will use Retrieval-Augmented Generation (RAG) to answer incident and troubleshooting questions using enterprise knowledge.

## Planned Stack

- Java 21
- Spring Boot
- Spring AI
- Maven
- Ollama
- PostgreSQL
- PGVector
- Docker
- REST APIs
